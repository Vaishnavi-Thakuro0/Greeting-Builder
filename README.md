# Greeting Builder

A small JavaScript greeting helper that creates greetings based on a person's name and time of day.

## Functions

- `formatName(firstName, lastName)` - Combines first and last name.
- `getGreeting(timeOfDay)` - Returns a morning, afternoon, or evening greeting.
- `createGreeting(firstName, lastName, timeOfDay)` - Creates the complete greeting.

## How to Run

1. Clone this repository.
2. Open `script.js` in a JavaScript environment such as Node.js or a browser console.
3. Call the `createGreeting` function with a first name, last name, and time of day.
